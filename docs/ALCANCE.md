# 🎯 EventProduction Hub — Alcance y Funcionalidades

> [!info] Panorama rápido
> Síntesis del [[opencode|Documento Maestro]] para arrancar sesiones con el contexto del proyecto. Para el detalle completo (visión, BD, flujos, guía técnica): lee [[opencode]].

## Misión

Plataforma integral que **centraliza y automatiza la gestión operativa de eventos medianos** en Ecuador: visibilidad en tiempo real, control financiero y análisis de datos históricos.

## Público objetivo

Productoras de eventos medianas (50–200 eventos/año) en Quito, Guayaquil y Cuenca. Equipos de 5–50 personas. Presupuestos de $5,000 a $500,000+ por evento.

## Funcionalidades pensadas por área

| Área | Funcionalidad |
|------|---------------|
| **Operativa** | Cronogramas, actividades, asignación de personal |
| **Logística** | Inventario, equipo, asignación a eventos |
| **Financiera** | Pagos, presupuestos, control de gasto |
| **Proveedores** | Directorio, histórico, rating automático |
| **Reportería** | Dashboards, KPIs, análisis post-evento |

## Stack

C# ASP.NET MVC + Entity Framework + SQL Server 2019+. MVP en desarrollo hasta octubre 2026.

## Roadmap post-MVP

- **SignalR:** actualizaciones en tiempo real.
- **Machine Learning:** predictor de retrasos basado en histórico.
- **App móvil:** iOS/Android.
- **Modo offline:** sincronización al reconectar.
- **Integraciones:** software contable y pasarelas de pago.
- **Analytics avanzado:** dashboards predictivos.
